# Atlas RAW — Épreuve du 2026-06-22

> Mise à l'épreuve de l'Atlas (`docs/raw/`) sur ses **3 promesses** : *usage* (point d'entrée unique,
> sans rouvrir `Source/`), *fidélité* (refs + citations + synthèse exactes), *couverture* (« 0 trou »).
> Déclencheur : la Source a été **ré-extraite à Marker le 2026-06-22**. Méthode hybride : un moteur
> **mécanique** (`scripts/raw/reanchor.mjs`, sur tout l'Atlas) + une **tranche de jugement** (combat,
> tests, états, destin). Tout défaut corrigé a été **relu contre la Source**.

## Verdict en une ligne

L'Atlas est un **bon point d'entrée au niveau de la PROSE** (≈ **24/26** questions RAW répondues sans
rouvrir la Source), mais son **système de réfs `l.X` était massivement périmé** après la ré-extraction
Marker. **Traité** : **322 citations verbatim re-ancrées** (match exact) + **2176 réfs de synthèse
re-ancrées par diff de contenu HEAD↔Marker** + **5 fabrications de contenu** corrigées. Hors-portée ici
(sur consigne) : les **1076 `// LDB l.X` du code applicatif**.

## Lentille 2 — FIDÉLITÉ

### A. Réfs `l.X` — dérive systématique post-Marker (corrigée mécaniquement)

`reanchor.mjs` re-ancre en deux passes : `--apply` (citations verbatim, par match exact — ancre = plus
long préfixe verbatim, tolère les retouches du build) ; `--remap` (réfs de synthèse, par **diff de
contenu** entre l'ancienne Source de `git HEAD` et la nouvelle Marker de l'arbre).

**Bilan : ✅ 322 verbatim justes · 🔧 0 dérive · 🟡 1 ambigu · ❌ 41 introuvables · 🧭 2176 synthèses
re-ancrées par diff** (⛔ 113 encore hors-fichier) sur **2586 réfs / 27 fiches de domaine**.

- **314 réfs verbatim auto-corrigées** (+ 1 manuelle). Avant épreuve : seules **5/363** citations
  pointaient la bonne ligne → **~86 % des réfs verbatim étaient dérivées**. La dérive n'est PAS un offset
  global (de −1 à −58 lignes selon le passage). Exemples : `LDB 13 l.34`→31, `LDB 12 l.25`→7,
  `LDB 18 l.28`→15, `LDB 05 l.389`→331.
- **2176 réfs de synthèse re-ancrées par diff** : l'ancienne Source (celle du build) survit dans
  **`git HEAD`**, on l'aligne sur la Marker (ancres = lignes uniques communes, LIS pour la monotonie,
  interpolation entre ancres). Carte **validée exacte** sur les points verbatim connus (34→31, 142→133,
  155→147) et au spot-check de contenu (`l.93-98` = règle d'Action). Le diff **translate fidèlement** mais
  n'invente pas : une réf imprécise à l'origine reste imprécise (déplacée, pas corrigée).
- **41 ❌ introuvables** = non réparables par texte : **tables** rendues en cellules Markdown par Marker
  (lignes de critiques `LDB 18`, Imparfaites `LDB 46`, armes `AA 01`), **décalages de chapitre**
  (contenu de `LDB 08` désormais en `LDB 07`, `LDB 22`→`LDB 21`, `LDB 15`→`LDB 14`…), et **paraphrases
  présentées comme citations** (cf. §B).
- **113 ⛔ synthèses encore hors-fichier** : chapitres trop peu ancrés pour le diff (< 3 ancres) ou
  décalés de chapitre (le contenu a changé de fichier — ex. `LDB 76` « schéma de profil » → `LDB 85`).
  À reprendre à la main (liste dans `reanchor.md`).

## Lentille 3 — COUVERTURE

- **Le « 0 trou » chapitre-niveau tient** (`coverage.mjs` : ✅ 114 · 🟡 4 · ⬜ 0). Mais cette garde
  mesure la **citation de chapitre**, pas la **justesse des lignes** — l'épreuve révèle un axe que
  `coverage.mjs` ne voit pas (les lignes étaient fausses partout).
- **Trous réels, mineurs** (renvois/flavour, pas de mécanique) :
  - `etats.md` : *Détermination retire À Terre → +1 PB* (`LDB 17 l.61`) ; clause « Se fatiguer : les DR
    rallongent le délai » (`LDB 16 l.97`) ; spectre des durées de repos (1 État/Round).
  - `combat.md` (cœur) : **critique côté défenseur** non rappelé dans le topic d'attaque (vit plus bas) ;
    clause « toucher au DR 0 » du tir dans le tas.
  - `destin.md` : renvois MJ (Ch.9 ; « décrire l'exploit » pour la Résilience) — non mécaniques.

## Headline & dette résiduelle

**Tout l'Atlas a été bâti contre l'extraction pré-Marker** : ses `l.X` ont dérivé en bloc le 2026-06-22.
**La dette n°1 est traitée :**
- ✅ **Verbatim** (363) : re-ancrées par match exact → 322 justes, 0 dérive. Garde rejouable `reanchor.mjs`.
- ✅ **Synthèse** (~2200) : re-ancrées par **diff de contenu** `git HEAD` (ancienne Source) ↔ arbre (Marker)
  via `reanchor --remap` → **2176 réfs déplacées sur la bonne échelle**, carte validée exacte. Migration
  **ONE-SHOT** (à relancer après chaque ré-extraction, **avant** de committer la nouvelle Source ; une fois
  committée, HEAD == arbre → carte identité → no-op).
- ⚠️ **Restes manuels** : 41 ❌ verbatim (tables/paraphrases/décalages de chapitre) + 113 ⛔ synthèses
  (chapitres peu ancrés ou décalés de chapitre) — listés dans `reanchor.md`. Le diff **n'invente pas**.
- ⛔ **Code (hors-portée, sur consigne)** : les 1076 `// LDB l.X` n'ont **pas de citation** → non
  ré-ancrables par texte, et le diff-remap ne vise que l'Atlas. **Conséquence assumée** : l'Atlas est
  désormais sur l'échelle Marker, le code sur l'ancienne → `reconcile.mjs` passe de Sens A **0 → 2**
  chapitres « lignes non pinées » (`LDB 05`, `LDB 12`, les seuls dont la dérive dépasse ±20). Signal
  honnête de **où** recaler le code quand il évoluera.

### Recommandations / reste à faire
1. **Décalages de chapitre + 41 ❌** : traiter à la main la liste de `reanchor.md` (« texte trouvé en
   LDB X l.N ») — peu nombreux, à fort impact (le diff ne change jamais un numéro de chapitre).
2. **Code (quand il évoluera)** : recaler les `// LDB l.X` des 2 chapitres signalés par `reconcile`
   (`LDB 05`, `LDB 12`) au moment où tu touches ces fichiers, pas avant.
3. **Rituel post-ré-extraction** : `node scripts/raw/reanchor.mjs --apply --remap` (verbatim + synthèse),
   avant de committer la Source. Alternative anti-dérive plus radicale : ancrer par §/titre, pas par ligne.
4. **Tracking git** : `docs/raw/` et `scripts/raw/` sont **entièrement non suivis** (jamais committés) —
   décider de les versionner (sinon l'Atlas + les gardes vivent hors-historique).

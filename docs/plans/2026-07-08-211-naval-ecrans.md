# Programme #211 — passe NAVAL : matérialisation ÉCRANS de l'attendu (2026-07-08)

> **Artefact daté**, compagnon de [`2026-07-08-211-naval-attendu.md`](2026-07-08-211-naval-attendu.md)
> (qui porte les règles RAW et leurs réfs — non répétées ici). Maquettes ASCII **conceptuelles** :
> elles fixent l'intention et la hiérarchie d'information, pas la géométrie finale.
> À SUPPRIMER une fois la passe close.

## Le langage de design (vaut pour TOUS les écrans)

1. **Jauges à crans gravés** : chaque seuil de règle (surcharge 100/120/140/150 %, bandes de Moral,
   Voie d'eau E/2 et E) est gravé SUR la jauge, pas expliqué à côté.
2. **Zéro malus silencieux** : tout franchissement de seuil, tout changement de vent, toute pénalité
   qui s'active = une ligne du journal + un changement visible d'état.
3. **Données dérivées plutôt que totaux** : l'écran affiche « autonomie 9 jours », « 12 bordées de
   poudre », « plafond d'investissement 86 Enc » — pas des sommes brutes à interpréter.
4. **Les flux se dessinent** : débordement couchettes→soute, projection fantôme d'un achat sur la
   jauge, part de l'Humeur dans un tirage — montrés, pas expliqués.
5. **Les mêmes widgets partout** : rose des vents, jauges du navire, silhouette à localisations,
   modale de jet collective — un seul exemplaire de chaque, incrusté là où il agit.
6. **Postes avant figurines** : chaque écran répond à « qui fait quoi », le héros-pion n'apparaît
   qu'à l'abordage.
7. **Responsive dès la conception** (charte : 900/700/560, utilisable à 360 px) : toute structure en
   colonnes dégrade en accordéons empilés.
8. **Tout est donnée** : ports, événements, profils de conduite, navires, pièces — le contenu de ces
   écrans s'édite au Compendium/éditeur.

# A. Le dossier de navire (l'objet persistant — 5 onglets)

Accessible PARTOUT (mer, escale, combat) : c'est la feuille de personnage du navire.

## A1. Onglet Profil — l'état d'un coup d'œil

```
┌─ LA HIRONDELLE — Barge · Taille 20 ─────────────────────────────────────┐
│  ▶Profil◀ │ Pont │ Soute │ Équipage │ Journal                           │
├────────────────────────────┬─────────────────────────────────────────────┤
│        [silhouette]        │ Voiles M 3 (É 3) · Avirons M 3 (É 4) · Man —│
│      ┌──── gréement ───┐   │ E 45 · B 54/60 (BB 5, recalculé) · Cont. 300│
│      │ ▓ coque         │   │ Traits : —                                  │
│      └─────────────────┘   ├─────────────────────────────────────────────┤
│  Voie d'eau  ██░░░░ 3/45   │ MORAL   ██████▒░░░ 66 « équipage satisfait »│
│    crans : E/2=22 · E=45   │ HUMEUR  ████░░░░░░ +12  ⚘ chat à bord       │
│  En flammes : non          │   ▸ historique des actes (7)                │
│  Salissures : niveau 1     ├─────────────────────────────────────────────┤
│  ⚠ Répa TEMPORAIRE : 1     │ ÉCHÉANCES   Conseil de bord ....... dans 3 j│
│    (Test E chaque jour)    │             Test de salissures .... dans 5 j│
│                            │             Paie de l'équipage .... dans 2 j│
└────────────────────────────┴─────────────────────────────────────────────┘
```

- La **silhouette à localisations** est LE portrait du navire — la même qu'en combat (bordée reçue)
  et au chantier (devis) ; les états s'y épinglent.
- La **Voie d'eau porte ses deux crans** (E/2 : −1 M −1 DR ; E : coule) — la mort du navire se lit.
- **Humeur = jauge + historique dépliable** : le joueur voit POURQUOI Manann boude (chaque acte,
  sa date, son modificateur — un acte ne compte qu'une fois, l'historique le montre grisé).
- L'**échéancier des cadences** (conseil, salissures, paie) rend le calendrier tangible — ce sont
  les « prochains arrêts sur image » du journal de bord.
- La **dette de réparation temporaire** est un ⚠ permanent, pas une ligne enfouie.

## A2. Onglet Pont — le plan des postes (partagé voyage/combat)

```
┌─ PONT — affectations ────────────────────────────────────────────────────┐
│                    PROUE                                                 │
│      [Pierrier]  ● chargé · servants 1/1 · balles et poudre             │
│  ┌────────────────────────────────┐    POSTES DU JOUR                    │
│  │        ◉ Elsa — VIGIE          │    Barre (Timonier)   ◉ Gunnar       │
│  │  ◉ Gunnar — BARRE              │    Vigie              ◉ Elsa (+1 DR) │
│  │        ○ Josef — PIERRIER      │    Pierrier           ○ Josef        │
│  │  ◉ Hilda — MOUSSE   ⚠ Grum ────┼──→ Mousse    ◉ Hilda · ⚠ Grum (+2cr)│
│  └────────────────────────────────┘    ── URGENCES ──                    │
│                    POUPE               ⚠ Écoper (voie d'eau) …… 1/2 bras │
│  Assiette ◄──█░──► équilibrée                                            │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le plan de pont est **l'écran d'ordres** : affecter quelqu'un = un geste (glisser ou cliquer-
  choisir). Un marin affecté est grisé partout ailleurs ce Round/ce jour.
- Le **cumul de rôles s'affiche à la personne** (⚠ +2 crans) — la règle est portée par le pion.
- Les **urgences APPARAISSENT comme des postes** (« Écoper 1/2 bras ») : l'arbitrage des bras se
  joue ici, en voyage comme en combat — même écran, cadence différente (jour ↔ Round).
- Les **pièces** portent leurs pastilles (chargée/recharge x/N, servants, munition) ; le fléau
  d'assiette est l'écho du placement (le déplacer = décision de chantier/pont, seuils 25/50 %).
- **En combat, cet onglet EST l'écran du Round** côté navire (cf. D1 qui l'embarque).

notre journal structuré habituel, au niveau navire.

# B. La mer (le mode voyage)

## B1. L'écran de voyage — le journal de bord qui défile

```
┌─ EN MER — jour 12 · cap sur Salzenmund (estimé : 3 j) ──────────────────┐
│  ◔ vent NE, fort (largue : M+1)  ·  ☁ bruine (visibilité réduite)       │
├───────────────────────────────────┬──────────────────────────────────────┤
│  CARTE (position ESTIMÉE ╳)       │  JOURNAL DE BORD                     │
│      ⚓ Dietershafen               │  J10  Orientation ✔ (cap tenu)       │
│    ~~~~ ╳~~~~~~                   │  J11  Le vent tourne NE (aube)       │
│   ⚠ détroit      ⚓ Salzenmund     │  J11  Grattements en cale… ⚠         │
│    ~~~~~~ route ────╮             │  J12  Quart du matin : RAS           │
├───────────────────────────────────┴──────────────────────────────────────┤
│  Soute 71 % · autonomie 9 j · Moral 66 · Humeur +12 · ⚠ répa temp.      │
│        [▶▶ Poursuivre la route]     [⚑ Mouiller]     [Dossier navire]    │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Le bouton ▶▶ est le cœur du mode** : il déroule les jours en accéléré (lignes de journal qui
  défilent, pion qui avance) et **s'arrête NET** sur toute échéance : événement (1d10 j), conseil
  (semaine), salissures, arrivée, voile à l'horizon. Le joueur vit les arrêts sur image.
- Le **pion montre la position estimée** — une Orientation ratée en silence fait mentir la carte,
  et c'est la côte qui n'arrive pas qui l'apprend au joueur.
- Le **bandeau du bas** = les chips des jauges (écho du dossier), cliquables.
- La rose des vents est LA même qu'en combat ; ses bascules sont des lignes de journal.
- **Deux vitesses RAW en un geste** : ▶▶ = jour par jour ; l'alternative « Voyage rapide (un jet) »
  est proposée au moment de tracer la route (B2) pour les trajets sans enjeu.

## B2. Tracer la route — le choix de risque

```
┌─ TRACER LA ROUTE — vers Salzenmund ─────────────────────────────────────┐
│   ⚓ Erengrad        ⚠ Gueule du dragon (rochers IC 60)                  │
│      ╲                                                                   │
│       ╲  route A ── haute mer ── 4 j · Orientation exigeante            │
│        ╲ route B ── cabotage ─── 6 j · phares (+), périls côtiers (⚠)   │
│   ⚓ L'Anguille ⟟────────⚓ Salzenmund                                    │
│  vents dominants : NE ↘ · autonomie requise : A=5 j, B=7 j (en cale: 9) │
│      [Partir — route A]   [Partir — route B]   [Voyage rapide (1 jet)]  │
└──────────────────────────────────────────────────────────────────────────┘
```

- Chaque route affiche son **profil de risque** (périls traversés, exigence d'orientation, appuis
  phares) et son **coût en autonomie** confronté à la cale — l'intendance rend le choix réel.
- Les périls sont des **zones sur la carte** (données de la géographie MDG 01-08) ; embaucher un
  pilote local (escale) neutralise une zone nommée.
- **[Voyage rapide]** = le mode RAW en un jet : Rude épreuve + Humeur → table à 5 paliers, résolu
  comme une mini-scène avec récit du palier obtenu.

## B3. Le conseil de bord — le rendez-vous hebdomadaire

```
┌─ CONSEIL DE BORD — fin de semaine 2 ────────────────────────────────────┐
│  MORAL 68 → ?                                        jets à vue         │
│   · La paie est généreuse ..................... +2d10   (7)   → 75      │
│   · Relâche refusée à Dietershafen ............ −2d10   (13)  → 62      │
│   · Vraie nourriture servie ................... +1d10   (4)   → 66      │
│   ⇒ MORAL 66 « équipage satisfait » (±0 DR aux Tests d'équipage)        │
├──────────────────────────────────────────────────────────────────────────┤
│  ACTIVITÉS DE LA SEMAINE (une par héros, en mer)                         │
│   ◉ Gunnar [Entraînement d'équipage ▾]    ◉ Elsa [Cartographie ▾]       │
│   ◉ Hilda  [Entretien du navire ▾]        ◉ Rolf [Artisanat ▾]          │
│                          [Tenir le conseil]                              │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le recalcul est **joué ligne à ligne devant le joueur** — chaque facteur est une conséquence
  de SES décisions de la semaine, et la jauge bouge en direct. C'est la récolte de A4.
- Les **Activités en mer** sont le catalogue d'Activités existant, filtré « à bord » + les 4
  spécifiques — même écran d'interlude, contexte différent.

## B4. L'événement — une mini-scène, jamais un toast

```
┌─ ÉVÉNEMENT DE BORD — Infestation de rats ! ─────────────────────────────┐
│  « Des grattements derrière les caisses de la cale… »                    │
│  (tirage 27 — dont Humeur de Manann −8)                                  │
│  Chaque nuit : 1d10 Enc de cargaison gâtés · 15 % de fièvre du rongeur  │
│  ▸ EXTERMINATION — Test d'équipage ÉTENDU   ████░░░░░░  4/10 DR         │
│     rôle essentiel : Mousse ★ (un Ratier peut l'occuper, fronde)        │
│        [Affecter des bras au poste]        [Laisser courir…]             │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le tirage **montre la part de l'Humeur** : la superstition a un effet lisible.
- Un événement à durée **s'installe** : il crée son poste sur le Pont (A2), sa jauge de Test
  étendu, et ses lignes de journal chaque nuit tant qu'il court.
- Les bascules lourdes (pirates, monstre) = le même cadre, avec [Aux postes de combat !] → D1.

# C. L'escale (le hub de port)

## C1. Le port

```
┌─ ESCALE — Salzenmund (Taille 3 · Richesse 4) ───────────────────────────┐
│  ⏳ un événement de port surviendra dans les prochaines heures…          │
│  PERMISSION DE RELÂCHE :   [Accorder]  +1d10 Moral · risque désertion   │
│                            [Refuser]   −2d10 Moral · équipage consigné  │
├──────────────────────────────────────────────────────────────────────────┤
│  ▸ Négoce        production : bois · demande : vin +2 ⚑ rumeur          │
│  ▸ Chantier      cale sèche : OUI · 10 CO/jour                          │
│  ▸ Recruter      6 profils disponibles (mousse 3 s/j … officier 15 s/j) │
│  ▸ Temple de Manann     bénédiction du navire · prêtre (1d10+3 CO)      │
│  ▸ Descendre à terre    (interlude / activités de ville)                │
│                         [Reprendre la mer]                               │
└──────────────────────────────────────────────────────────────────────────┘
```

- La **permission de relâche est LA décision d'entrée**, à double tranchant affiché.
- Les entrées du menu sont pilotées par les **données du port** (5 indices + services) : un port
  sans cale sèche n'affiche pas le carénage, un port skaeling n'a pas de temple de Manann.
- L'**événement de port** tombe pendant qu'on y est (2d10 h, ±Humeur) — l'escale n'est pas un
  menu figé, elle vit.

## C2. Le négoce

```
┌─ NÉGOCE — Salzenmund · automne ─────────────────────────────────────────┐
│  ACHETER                    prix/10 Enc   disponible                     │
│   Bois (production)            2 CO        340 Enc      [ − 0 + ]       │
│   Laine (surplus, +1 DR vend.) 1 CO        180 Enc      [ − 80 + ]      │
│  VENDRE                                                                  │
│   Vin — 40 Enc en soute · demande +2 ⚑ → offre 4 CO/Enc  [Marchander]   │
├──────────────────────────────────────────────────────────────────────────┤
│  SOUTE  ██████████▒▒▒░░  214 → 294/300   ⚠ projection : 98 %            │
│  Bourse : 62 CO 14 s                     [Conclure]                      │
└──────────────────────────────────────────────────────────────────────────┘
```

- La **projection fantôme** sur la jauge de soute (▒) est l'âme de l'écran : on VOIT l'achat
  remplir la cale et frôler le cran de surcharge avant de conclure.
- Prix **saisonniers et géographiques** affichés avec leur raison (production/surplus/demande) —
  la spéculation se lit, et la rumeur commerciale (⚑) est un modificateur visible et daté.
- [Marchander] ouvre la **modale de jet standard** (Test opposé) — pas un mini-jeu à part.

## C3. Le chantier naval

```
┌─ CHANTIER — Salzenmund (cale sèche) ────────────────────────────────────┐
│  DEVIS                                                    coût    durée │
│  ▸ Réparer la coque (6 Blessures)                         6 CO    ~6 h  │
│  ▸ Résorber la réparation TEMPORAIRE ⚠ (dette quotid.)    inclus        │
│  ▸ Carénage — salissures niveau 1 (−1 DR Man)            11 CO    2 j   │
│  ▸ Installer une amélioration : Nid-de-pie (+1/+2 DR)    25 CO    1 sem │
│  ▸ Commander un navire neuf… → CONFIGURATEUR                             │
├──────────────────────────────────────────────────────────────────────────┤
│  Immobilisation : 9 jours — salaires courent (42 s/j = 3,8 CO)          │
│                        [Lancer les travaux]                              │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le devis affiche toujours **coût + durée + ce que la durée coûte** (salaires, calendrier de
  campagne) : réparer est une décision de planification, pas un clic.
- Le **configurateur** (commander/construire) est le pendant maritime de la création de
  personnage : Taille → propulsion → style (curseurs vitesse⇄Contenance⇄Man qui font bouger le
  prix ET les jauges en direct) → Traits/Améliorations. Tout en donnée.
- La silhouette à localisations sert d'**écran de devis** : cliquer une avarie = sa ligne.

# D. Le combat naval

## D1. Le ruban de Distance — l'écran de bataille (acte I)

```
┌─ POURSUITE — langskip skaeling ➜ LA HIRONDELLE ─────────────────────────┐
│  ÉVASION 70 ╣═════════════╪══════════╪═════╪═══════╫ 0 ABORDAGE         │
│                        Distance 24 ◆                                     │
│              portée canon (eux) 15 ┘     └ 3 pierrier (nous)            │
│  ◔ vent NE · nous largue M+1 · eux vent arrière M+2       [⏩ ×10]      │
├──────────────────────────────────────────────────────────────────────────┤
│  ROUND 4 — Initiative : eux, puis nous                                   │
│  ▸ NAVIGATION (fuite) — Mousse ★ · 3 contributeurs        [Lancer]      │
│  ▸ PIERRIER — chargé · hors d'arc (encore 2 points)                     │
│  ⚠ ÉCOPER — voie d'eau 3 · poste 1/2 bras            [→ Pont]           │
│  ── eux : le langskip force à la rame (annonce de la vigie) ──          │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le ruban porte TOUT l'enjeu : le curseur ◆ de Distance entre le seuil d'ÉVASION (gauche) et le
  CONTACT (droite), et **les marques de portée des deux bords** — on voit à combien de points le
  premier boulet devient possible, dans les deux sens.
- **[⏩ ×10]** matérialise l'horloge à deux vitesses : disponible tant qu'aucune interaction n'est
  possible, il saute des tranches de 10 Rounds ; il se désactive avec fracas au premier seuil
  franchi (« À portée extrême ! »).
- Le bas d'écran est la **liste des décisions du Round** (navigation, pièces, urgences) — chaque
  ligne renvoie au Pont (A2) pour les affectations. La vigie **annonce** les intentions lisibles
  de l'adversaire (il force, il charge) : le profil de conduite ennemi s'exprime en récit.
- **Adversaire créature** : même ruban, la silhouette d'en face est un monstre ; un Broyeur
  accroché remplace le curseur par une **horloge de mort** (DR cumulés / Blessures du navire) avec
  les deux contre-jeux affichés (le blesser >7, le décrocher en Force).

## D2. La modale de Test d'équipage — le jet collectif

```
┌─ TEST D'ÉQUIPAGE — Manœuvre (éviter les récifs) ────────────────────────┐
│  Timonier ★×2   ◉ Gunnar   Voile 52 · Man —      [🎲 47 ✔ +1] ⇒ +2 DR  │
│  Mousse         ◉ Hilda    Ramer 41              [🎲 88 ✘ −1] ⇒ −1 DR  │
│  Mousse ⚠+2crans ○ Grum    Ramer 45→25           [🎲 …]                 │
│  Moral 66 : ±0 · équipage complet : pas de malus                        │
│  TOTAL  ▓▓░░░  +1 DR   (succès si ≥ 1)                                  │
│                          [Résoudre]                                      │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Une ligne par contributeur, chaque joueur lance SA ligne** (en coop, chacun la sienne — c'est
  le moment multijoueur natif ; en solo on les enchaîne). Le rôle essentiel porte son ★×2.
- Le **pot commun de DR** se remplit ligne à ligne vers le seuil ≥1 — le suspense est structurel.
- Les malus systémiques (Moral, sous-effectif, cumul) sont des lignes du récapitulatif, jamais
  des soustractions invisibles.
- C'est LA même coquille de modale de jet que partout ailleurs dans le jeu, en mode multi.

## D3. La bordée — le résumé de salve

```
┌─ BORDÉE ! — Test d'équipage : +3 DR partagés (Artilleur ★) ─────────────┐
│  pièce           munition    servants   touche   localisation    effet   │
│  Canon bâbord 1  boulet      3/3 ✔      +3       GRÉEMENT       9 dég.  │
│  Canon bâbord 2  mitraille   2/3 ⚠      +2 impr. ÉQUIPAGE   → 2 marins  │
├──────────────────────────────────────────────────────────────────────────┤
│        [silhouette ennemie — gréement ▓ voile déchirée, −1 M]           │
│  Après tir : 2 pièces en RECHARGE (4 Rounds · ×2 si sous-effectif)      │
└──────────────────────────────────────────────────────────────────────────┘
```

- Le DR **partagé** s'applique à chaque pièce « pour le meilleur et pour le pire » : le tableau le
  rend littéral — une colonne touche commune, des localisations et effets par pièce.
- Les impacts **se peignent sur la silhouette ennemie** (le même widget que A1, côté adverse).
- La sortie annonce le **métronome** : quelles pièces se taisent, pour combien de Rounds.

## D4. La collision — le duel de barreurs

```
┌─ COLLISION IMMINENTE ! ─────────────────────────────────────────────────┐
```

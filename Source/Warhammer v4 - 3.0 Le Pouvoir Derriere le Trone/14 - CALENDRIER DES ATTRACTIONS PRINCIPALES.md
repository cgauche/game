### INFLUENCER LE GRAF

Le Graf de Middenheim est le seul à pouvoir édicter des lois : les Seigneurs des Lois le conseillent, mais sans son accord, une loi ne peut être instaurée. 11 personnes ou groupes de personnes peuvent influencer le Graf à des degrés variés. Ces groupes et le poids de leur influence, exprimée sous forme de 17 « votes d'influence », sont les suivants :

0 Sparsam, le Chancelier : 2 votes

0 Schmiedehammer, le Champion : 1 vote

0 Lafarel, le Ménestrel de la Cour : 1 vote

0 La « princesse » Katarina : 3 votes

0 Zimperlich, le Chaperon : 1 vote

0 Les Middenmarshalls : 1 vote

0 Les sorciers : 1 vote

0 Le Grand Prêtre d'Ulric : 1 vote

0 Emmanuelle, la favorite du Graf : 2 votes

0 Pavarotti, le Médecin de la cour : 1 vote

0 Les Seigneurs des Lois : 3 votes

Il existe bien entendu d'autres groupes capables de murmurer à l'oreille du Graf de temps à autre ; le Culte d'Ulric et de Sigmar, la Guilde des Marchands, d'autres guildes, certains petits nobles, etc., mais ce cercle intérieur est celui qui l'influence le plus, notamment dans l'état dans lequel il se trouve présentement.

Wasmeier contrôle 9 des 17 votes, ce qui lui assure la victoire, même si les autres se prononcent contre les taxes. Il a obtenu le soutien du Chancelier Sparsam (2 voix), des Seigneurs des Lois (3 voix), d'Emmanuelle et d'Ar-Ulric (3 voix) et du Champion (1 voix).

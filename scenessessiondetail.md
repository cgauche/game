# Les scènes de la session — détail
*Interlude Altdorf → départ. In-game : à partir du **33 Sigmarzeit 2512**. Fin = embarquement sur **La Comète** (= fin ch.8).*
*Calendrier : climax 9 Brauzeit 2512 → ~140 j de marge → **aucune urgence**, la planque rentre large.*
*Beats côté MJ : tu poses les situations, les joueurs mènent. Balisage **[C]** canon / **[T]** connectif-table.*

## Scène 1 — Ancrage : Immanuel formalise **[C + T]**

**Situation.** On reprend après le chevet (fin S63). Les PJ sont **chauds** (Yuridika nommée, Fassbinder arrêté). Leur lien vers la sécurité, c'est **Johannes → Immanuel**, qui leur a « laissé une chance » à 17h. Maintenant qu'ils ont la **preuve** (Kappelmuller en fuite = aveu, sort confirmé par Anselm, enfant-Gideon identifié), Immanuel **s'engage à fond**.

**Ce que la scène pose.** La **protection** (la planque), la **rumeur Middenheim** (couverture : « ils sont partis au nord avec les Todbringer »), et l'**offre de postes / changements de carrière Graukappen** (cf. dernière section).

**PNJ.** Immanuel-Ferrand (Grand Chancelier, sorcier gris, maître-espion — **diplomate posé, froid, qui calcule** ; je ne te scripte pas ses répliques) ; Johannes (le courtier) ; Maria-Luise peut corroborer côté palais.

**Ancrage.** **[C]** Canon ch.8 « Who Makes the Suggestion » : PJ autonomes **+** affaire de l'empereur empoisonné découverte → Immanuel et/ou la famille impériale commanditent. **[C]** Les Graukappen + le sondage-recrutement (« I'm sure we understand each other »). **[C]** La couverture Middenheim (« treated as if returning to Middenheim with the Todbringers »). **[T]** La planque elle-même (le canon les fait partir vite — ici on étire).

**Tests utiles.** Surtout du RP. La preuve fait le travail (la **convergence** suffit à le faire basculer, canon). Pas de jet imposé ; au besoin Cool/Charm pour le ton.

**Embranchements (à eux).** Acceptent-ils la protection + les postes, ou juste l'abri ? Font-ils pleinement confiance à Immanuel ? *(Ils devraient — il est sincère.)*

**Sous la table (MJ).** Accepter les Graukappen = entrer **dans le réseau noyauté par Zuntermein**. Coût caché, à ne pas révéler.

## Scène 2 — Jalon ① : la chasse se resserre puis retombe **[T, sur fond canon]**

**Situation.** La **chasse sigmarite** est le danger réel et *ressenti*. Un **frôlement** : balayage du Marteau d'Argent / patrouille du Comité de Vigilance près de la planque, ou passage tendu si un PJ doit bouger. Puis, sur quelques jours, la rumeur Middenheim + l'influence d'Immanuel + les **crises plus grosses d'Altdorf** font **retomber** le manhunt.

**Ce que la scène pose.** La tension de la séance (la menace qu'ils perçoivent), puis la **résolution du jalon ①**.

**PNJ.** Répurgateurs du Marteau d'Argent (ceux qui ont pris Fassbinder — les PJ **ignorent** le lien Zuntermein) ; **Comité de Vigilance Citoyen** ; la foule. Les gens d'Immanuel qui tiennent la couverture.

**Ancrage.** **[C]** Le Comité de Vigilance (ch.8 : « barely veiled thuggery »), le Marteau d'Argent, la ville en émeute. **[C]** La couverture Middenheim. **[T]** Le rythme « se resserre puis retombe ».

**Tests utiles.** S'ils doivent se montrer/bouger : **Discrétion (Urbaine)**, **Déguisement / Représentation (Comédie)**, ou les **illusions de Johannes** (Mutable Visage, Linceul…). **Cool/Intimidation** si coincés. *Idéalement ils restent terrés (travail de cabinet) → pas d'exposition.* Le travestissement, c'est **pour bouger**, pas pour la planque.

**Embranchements (à eux).** Rester cachés (malin) ou rompre la couverture (risqué) ? **Yuridika** (la nommée) = le plus haut risque — elle tient en place ou elle ronge son frein ?

## Scène 3 — Jalon ② : l'empereur se relève **[C (issue) + T (processus)]**

**Situation.** Sur les jours de planque, le mal de l'empereur **se lève**. **Personne ne le soigne** (on l'a établi : impossible) — c'est **Gideon qui décroche** (couverture morte, il se recentre sur le 9 Brauzeit). Processus **visible** : la **Caresse de Rhya** d'Elvira (effet *Guérir Blessures* seul) ouvre des **fenêtres de lucidité** (il parle, puis se repose) ; puis, Gideon cessant de ré-infliger, il **remonte vraiment**.

**Ce que la scène pose.** La **précondition de départ** que tu as fixée ; la clôture du fil maladie ; = le **−2 Power** au climax.

**PNJ.** Karl-Franz (convalescent, frêle, intervalles lucides → mieux) ; Maria-Luise à son chevet ; Anselm/Elvira aux soins.

**Ancrage.** **[C]** ch.8 « Kappelmuller exposé → l'empereur se rétablit » ; **[C]** ch.13 −2 Power. **[C]** Mécanique maladie (Blight magique, ni dissipation ni Caresse — seul *Guérir Blessures* opère). **[T]** Le rétablissement joué **comme processus pendant la planque** (le canon le met hors-champ).

**Tests utiles.** **Invocation (Rhya)** d'Elvira → fenêtre lucide (Blessures, pas la maladie). **Seconde Vue / Connaissance (Médecine)** d'Anselm → constater le résidu magique qui **se retire**. **Soin** pour l'accompagnement.

**Embranchements (à eux).** Restent-ils dans sa garde rapprochée ? Dans une **fenêtre lucide**, l'empereur dit/signe-t-il quelque chose d'utile (appuyer leur mission, donner du poids à Maria-Luise) ? *(À toi/eux — pas scripté.)*

**Sous la table (MJ).** S'il se rétablit, ce n'est pas un mérite de soin : c'est **le démon qui lâche prise**. Garde-le pour toi.

## Scène 6 — Clôture : le départ sur La Comète **[C]**

**Situation.** Les **deux jalons atteints**, Immanuel **finalise la commission** et **dépêche La Comète** (patrouilleur fluvial + Marines) **vers Averheim**. Embarquement **discret** : la couverture Middenheim a tiré l'attention au **nord**, ils glissent au **sud** vers les quais.

**Ce que la scène pose.** Fin du ch.8, lancement du ch.9.

**PNJ.** Immanuel (commission finale, éventuel mot d'adieu) ; l'équipage de La Comète **[C]** ; Johannes embarque ; **silhouette Gideon possible au quai** **[C]**.

**Ancrage.** **[C]** La Comète (River Patrol + Marines, cap Averheim, ch.8). **[C]** Transition → ch.9. **[T]** **La mise en scène de l'embarquement** (quel quai, sous quelle couverture, qui les accompagne) — **le seul morceau que le canon te laisse entièrement à poser.**

**Tests utiles.** Trajet vers les docks sous la chasse : **Discrétion / Déguisement** au besoin (mais l'attention est partie au nord).

**Embranchements (à eux).** Quel quai, quelle couverture, qui les voit partir ; laissent-ils quelqu'un/quelque chose (Albert convalescent chez Shallya, Pesold parti avec Heinrich).

## Les changements de carrière (offre Immanuel) **[C base + WFRP]**

**Cadre.** L'**intronisation Graukappen** = la **justification in-fiction** (WFRP 4e : 100 XP + raison + nouveaux trappings). Canon : Immanuel **sonde déjà** les PJ pour ça.

**Voies.** Renseignement/agent (core 4e) : **Espion**, **Émissaire**, **Conseiller** (Courtisan), **Enquêteur**, **Agitateur** (Bourgeois). Spécialistes : **avancement d'ordre** sous son patronage (il est sorcier gris).

**Par perso.** **Phineas** (Artiste/Courtisan) = candidat idéal → Espion/Émissaire/Conseiller (couverture parfaite). **Johannes** → avance Ordre Gris + liaison. **Anselm** (Azyr) → divination au service du renseignement / Conseiller. **Elvira** (Rhya) → sert par la foi (elle veille l'empereur) / Conseiller. **Mark** (Ulric) → profil bas / rôle martial discret. **Yuridika** (Chamon) → planquée au Collège Gris / avancement magie.

**Sous la table (MJ).** Devenir Graukappen = entrer dans le réseau de **Zuntermein**. Leur promotion a un **prix qu'ils ignorent** — à mettre en banque.

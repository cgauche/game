Refonte TOTALE de la couche rendu (2026-07-02, 8 lots, spec `docs/superpowers/specs/2026-07-02-refonte-rendu-design.md`). Motif : après empilement de features (verticalité, murs d'arête, multi-niveaux, edge-on, POV, apparence JSON), l'utilisateur n'était satisfait NI du visuel NI du code.

**Architecture cible atteinte — « une scène, une apparence, N projections » :**
- **Pivot** `src/gameIso/builders/types.ts` : `SceneEl` (floor/wall/roof/prop/token), `Face{poly: GP[], plane, material, detail?}` en coordonnées MONDE (grille continue + h en MÈTRES) — jamais de rotation ni d'écran. Les builders n'importent NI `Dims` NI caméra.
- **Builders purs** `builders/{floors,walls,roofs,props,tokens,highlights}.ts` : dérivent la scène en éléments sémantiques + états de SCÈNE (visible/down/open/overhang/roofOccupied). UNE dérivation par préoccupation (relief, arêtes `wallEnds` 4→1, occlusion, pans de toit).
- **2 backends** : `backends/affine*.ts` (iso losange / edge-on / top — projette via [[game-iso-depth-z-secondary]], tri `depth()`) ; `pov/*` (perspective pinhole `camera.ts`). Les DEUX dessinent les mêmes faces/recettes, chacun à SA résolution (pas de parité pixel).
- **Stage fin** : `IsoStage.tsx` **1859 → 243 lignes** (coquille : état→builders memoïsés→backends→fusion→JSX) + `stage/*` (14 modules + hooks `useStageCamera`/`useStagePointer`/`useHoverTargeting` + overlays d'INTERACTION en sous-composants). Fix re-tri 60 Hz : couches statiques triées 1× par memo, insertion dichotomique des dynamiques (`mergeByDepth`).

**Apparence 100 % DONNÉE** : `src/data/{structureAppearance,reliefMaterials,roofMaterials,ambiance,decorPalette}.json` + terrain defs + `shade.ts` (SEULE source de lumière ; identité = JSON) — API : `shade(hex,k)` (luminance ×k, clampé ; `var(--x)` passe tel quel), `mix`, facteurs de lumière (`SIDE_N=0.86`, `POST_CAP/BASE`), voiles `ao/spec/warm` ; calibré pour reproduire l'existant au lancement de la migration (bois iso ±3/canal). Recettes de détail « dessiné main » : `detail/{types,expand}.ts` (`DetailRecipe`→primitives UV) consommées par `backends/affineDetail.ts` (règle **pattern = joints partagés par matériau×orientation, fill = couleur teintable** ; accents seedés `hash32(identité monde)` ; LOD par zoom). Décor : 97 defs consomment `decorPalette` (tons nommés), ZÉRO hex. Garde-fou `renderer-no-hardcoded-color.test.ts` couvre tous les renderers d'environnement.

**Gains visuels clés** : toits en PANS CONTINUS (fin de la mosaïque/zigzag — `roofFromCells` supprimé, fusion coplanaire + selles triangulées) ; pierre/bois appareillés ; POV profond (portée 32, brume smoothstep, grille au point de fuite, silhouettes de brume pour le hors-vue — cf. retour user « manque de profondeur ») ; défaut de chargement corrigé (`camEdge:false` = losange lisible, plus l'edge-on illisible) ; POV spawn orienté vers le contenu (`spawnFacing`).

**Instrument de non-régression** : `npm run qc:env` → planches contact `public/qc/env-*.png` (4 scènes × iso 4 rot / edge 4 rot / top / POV 2 caps). Comparer avant/après à CHAQUE lot (SVG affine byte-identique pour les refactors iso-visuels).

Supprimés (zéro doublon vivant) : `ground.ts`, `walls.ts`, `RoofSprite.tsx`, `catalog/buildings/render-helpers.ts` (roofFromCells), `placeSprite`. Point de départ : la migration « apparence JSON + renderers purs » du 2026-07-01 (Phase 3b y avait déjà supprimé le sous-système bâtiment mort `colombage`/`hipRoof`/`openings`/`timber`/`wallFaces`/`BUILDINGS`/`buildingLayers`, ~200 l., avant que cette refonte ne remplace le reste).

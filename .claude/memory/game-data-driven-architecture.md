Trois abstractions unifiantes (contenu extensible SANS toucher au code applicatif) :

- **A. Règles optionnelles** (`src/engine/policy.ts` : registre `OPTIONAL_RULES`, 1 règle = 1 entrée + store de surcharge + `rule(id)`) — activables EN JEU (`HouseRulesModal` généré depuis le registre, persisté `wfrp4.house-rules.v1` via `state/houseRules.ts`). `TEST_POLICY` (`engine/testPolicy.ts`) = producteur unique de `TestResult` (bandes auto 01-05/96-00, DR, `maxForcedRoll`). **Catalogue complet ~60 règles optionnelles** persisté `docs/regles-optionnelles-{catalogue,playbook}.md` (par sous-système + statut DO/HEAVY/FAUX-POS) — ~31 livrées + refacto création + 3 sous-systèmes neufs (Voyage par Étapes `travelStages.ts`, couche sociale de Statut `engine/social.ts`, Longueur d'arme `weaponReachPenalty`).
- **B. Content-effects** : `GameOp` (`engine/ops.ts`) exécuté par `applyOps`, dispatché par des registres `defs/` (codegen `scripts/gen-registry.mjs`). Cultes (`engine/cults/defs/`), psychologie (`engine/psych/defs/`), sorts — TOUS migrés en GameOp/donnée (cf. ci-dessous, sorts B4 terminé).
- **C. Content app-owned** : `src/data/*.json` = SOURCE canonique éditable (le pipeline `all-data.json → build:data` a été RETIRÉ, il écrasait les données curées). Édition **DANS le Compendium** (toggle DEV « ✏️ Éditer » → `CodexEdit`, champs inférés de la donnée + autocomplétion `<datalist>` sur les références) — PAS un éditeur autonome séparé (`src/ui/dataEditor/` supprimé après retour user : dupliquait le Compendium, moins bien, pas d'aide à la saisie). Fondation : `src/data/overrides.ts` (`setDataset`/`resetData` mutent EN PLACE, jamais de réassignation) + `serializeDataset` (round-trip byte-fidèle, `JSON.stringify(_,null,2)` sans newline finale) + `fsPersist.ts` (File System Access API : connect/restore handle IndexedDB, repli `downloadText`). **Recette = MANUELLE** (le folder-picker FS-Access n'est pas automatisable Playwright).

**Modèle de créature unifié** (espèce→sous-type→nommé ; LDB=sous-types `title=null`+optionals, nommés=`title`, partition par title/optionals PAS par livre) : le **match-par-nom du rig (POC regex) a été TUÉ** sous golden-master — bipèdes migrés en **aliases data** (`bipedSpeciesMatch` via `matchIn` name+aliases, champ `match` retiré) ; non-bipèdes déjà alias-based. ⚠️ `bipedSpeciesMatch` est LOAD-BEARING (synonymes de contenu réel : labels creatures.json type « Guerrier des clans »→Skaven) → ne jamais swap en lookup-only (bug silencieux). **Reste de-POC** : carrière `detectCareer`/`ROLE_CAREERS` (PNJ génériques arène → migrer carrière explicite sur entité), `isMutant`.

**Sorts (B4) TERMINÉ** : 243/243 sorts curés en `GameOp` ; le repli regex (`fallbackSpec`) est **SUPPRIMÉ (code mort)**. Nouvelles ops/champs : `gainFortune`/`gainFate` (retrait des non-dépensés à l'expiration), `SpellSpec.lifeSteal` (vol de vie missile), `SpellSpec.casterOps` (effets sur le lanceur), `ZoneEffect.heal`. **Moteur d'invocation** (`state/summonFlow.ts` : `applySummon`/`purgeExpiredSummons`) fait entrer une créature du bestiaire en combat, insérée dans l'initiative, dissipée au franchissement de Round. `enchantWeapon.onHitTest` : Test à la touche gaté par Groupe (`onlyGroups`/`exceptGroups`). Restent en `narrative` (limite RAW acceptée) : enchant +DR Dégâts/ignore-PA, Péché sur fausse accusation, polymorphe à remplacement de carac, scrying.

**Refonte combatFlow — PLAN 7 PHASES COMPLET (7/7)** : god-files (combatFlow ~4065 l., store ~3678 l.) décomposés via le patron DÉJÀ existant `cascadeAppliers` (registre peuplé par effet de bord d'import). Cible `state/combatHooks.ts` (`registerCombatHook`/`runCombatHooks`, cycle de vie battleStart/turnStart/turnEnd/roundBoundary/attackResolved/castResolved/miscast/battleEnd, filtré par `policy.rule`). Livré : boucles de Round → `state/combat/roundHooks.ts` ; `runEnemyAI` → `state/combat/turnHooks.ts` ; `applyAttackResult` → registre `state/combat/hitModifiers.ts` (ward-saves/arrow-ward/dome-ward/martyr/pushback, ordonnés) ; générateur `rollFlowActions`/`rollFlowActionsMulti` (types mappés template-literal, surface prouvée identique par tsc) ; god-switch `applyEffects` → registre `EFFECT_HANDLERS` (`combatEffects.ts`, exhaustivité par type mappé `{[K in Effect['type']]:...}`) ; manifeste `STATE_FIELDS` (`stateFields.ts`, `initialFields()`/`resetFields(scope)`) ; `~2025 l.` de combat inline → `src/state/combatSlice.ts` (`createCombatSlice`, store 3449→1424 l., **surface prouvée identique : 425 clés `useGame.getState()` avant==après**). **3 goldens protègent l'iso-comportement** : `roundBoundary.golden.test`, `turnStart.golden.test`, `hitSaves.golden.test` — à relancer après toute retouche combat.

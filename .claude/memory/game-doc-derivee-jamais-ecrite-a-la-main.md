Doctrine utilisateur (2026-07-27, verbatim) : « La documentation doit etre généré, jamais écrite a la main (vu qu'elle va périmer tres rapidement), depuis le code lui même comme on a fait pour Op/Flow. Ca doit etre généralisé pour tout. Et si cela demande de la discipline dans le code, on mettra de la discipline et des guards pour s'assurer que c'est respecté. »

**Why:** la doc est ce qui expose l'information pertinente à un agent ; un fait recopié périme sans bruit et fait décider faux.

**How to apply:** un fait vérifiable par la machine se DÉRIVE (générateur + garde), jamais recopié ; le manuscrit se limite à ce qu'aucune machine ne peut déduire (doctrine, arbitrage). Étendre le générateur plutôt qu'ajouter une ligne à la main.

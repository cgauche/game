**Intention de projet (énoncée par l'user 2026-07-05, à respecter dans toute décision d'archi sur les jets/coop).**

But : en coop, permettre à un joueur de **jouer le MONDE comme un MJ** — prendre le contrôle des ennemis ET des jets du monde (Ragot/Disponibilité du marchand, etc.). Raison : le MJ doit **comprendre les mécanismes** côté monde exactement comme le joueur les comprend côté héros — par le MÊME surfaçage (le jet remonte : cible, modificateurs, Chance/Résilience visibles). Symétrie : un seul système de remontée, deux publics.

**Conséquence architecturale — l'invariant « jet silencieux » est sur l'axe CONTRÔLEUR, pas le kind** :
- Un jet remonte à QUI CONTRÔLE ce camp : siège joueur→héros, **siège MJ→ennemis+monde**, IA→inline (seul camp sans humain assis).
- NE JAMAIS coder en dur « héros = différé / ennemi = silencieux » ni « jet du monde = ambiant pour toujours » — ça bloquerait le siège MJ. Le bon prédicat : **humain-contrôlé ⇒ passe par le système différé** (`pending*`/cascade) ; IA-contrôlé ⇒ inline.
- La couture EXISTE déjà : `resolveFlowTest` branche « **manuel** vs auto/IA » (manuel = notion de contrôleur, aujourd'hui câblée à « héros ») ; la coop a un transport/intents PAR SIÈGE (RoomHost) ; `RollShell` MULTI = N contributeurs coop. Le siège MJ = **découpler « manuel » de « héros »** (assigner le siège ennemi/monde à un humain → ses jets deviennent « manuel » → routent vers SES modales), pas une réécriture.

**NE PAS CHASSER chaque jet silencieux un par un** (demande explicite user) — c'est le même piège que la whitelist. La solution est STRUCTURELLE : UN **point d'étranglement de résolution conscient du contrôleur** par lequel TOUTE résolution de Test passe ; c'est lui qui tranche remonter-vs-inline selon le contrôleur (siège humain→remonte à ce siège, IA→inline). Alors : plus de résidu à traquer (tout passe par le choke par construction), plus de « silencieux pour toujours » codé en dur (le choke lit le contrôleur → siège MJ = flip de config), garde trivial (« rien ne résout un Test hors du choke ») → whitelist morte. Forme propre (fidèle à « contenu = donnée ») : Tests en nœuds Flow `test` coulant par LE routeur unique `resolveFlowTest` rendu **contrôleur-aware** ; les rares appels IMPÉRATIFS restants (chirurgie/exposition — set BORNÉ prouvé fini par l'audit 2026-07-05, le combat étant déjà propre) **consolidés dans le système différé partagé (commits db7ca6c9 trample, 626f1bc5 manœuvres, 38740d26 Hurlement, fec5dbad chirurgie+exposition ; Ragot=monde-ambiant légitime laissé)** — la CHASSE est finie, set VIDE.

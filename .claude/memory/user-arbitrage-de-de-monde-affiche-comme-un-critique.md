Verbatim utilisateur (2026-09-04) : « Tu sais ce que j’ai dit sur les jets. Si on a un jet, on doit pouvoir le lancer/fixer le dé a partir du moment ou le jeu est paramétré pour (ici controller l’environnement/activer la possibilité de fixer le dé), ca inclus même le jet de dispersion. »

**Why:** l’outil peut servir à simuler une partie de JDR comme Foundry — tout lancer passe par le même dialogue, donc aucun site n’a de question à se poser.

**How to apply:** un site envoie son dé au point d’entrée unique des jets sans se demander ni la nature du dé (Test, table, magnitude, dispersion) ni si le jeu est configuré ; un dé tiré hors de la porte est une dette vers zéro, et toute taxonomie qui exempte un dé (« magnitude », « conséquence canonique », « journalisé suffit ») se réfute.

**Verdict consolidé** : le pivot géométrique ([[game-refonte-rendu-builders-backends]]) tient (builders sans caméra/store, top confiné aux backends). Ce qui n'a JAMAIS été unifié : (a) la SÉMANTIQUE de rendu — occlusion/tri/visibilité vivent N fois à la main par backend (~40 sites de règles spéciales ; 2 tris indépendants : 9 offsets iso vs FLOOR_BIAS/FLOOR_ZLIFT+6 biais POV ; 2 cutaways parallèles roofHidden-bbox vs clearedSpace ; même bug « dalle enterrée » corrigé 2× — une fois par moteur) ; (b) le MODÈLE DE CONTENU (grain « une case, un sprite, 4 m »).

**POV = demi-moteur parallèle** : contourne `buildTokens` (re-scan `scene.entities`, kind `personnage` seul → montures/non-bipèdes invisibles), neutralise la visibilité du pivot (`buildFloors(scene, undefined)` → viewTruth « tout visible ») et recalcule la sienne, ignore `state.explored` (zéro brouillard persistant), zéro overlay joueur, importe des internes d'affine (`COURSED`, `TINT_SPREAD` — frontière trouée).

**Props** : 116 defs, 5 directionnelles ; plafond STRUCTUREL 4 silhouettes (`ViewArt` = front/profile/back + miroir) ; aucun ancrage arête/fraction de case ; escalier = meuble-pictogramme sans géométrie (POV : 0/11 fichiers).

**Modèle de contenu — impossibles mesurés** : étage habité simultané (activeZ unique), mur hauteur variable (`WallSeg` sans champ hauteur, `WALL_H_M=4` en dur → pas de muret/garde-corps/comptoir-cloison), escalier 1-2 cases pour 4 m (`minFlightCells` exige ≥4 ; ni colimaçon ni trappe), fenêtre traversable/source de jour (décorative stricte), lumière par pièce (scalaire global), toit-terrasse/dôme, eau graduée. Contenu réel plafonne à 2 couches (18 scènes campagne toutes z0). Porte-à-faux vertical aligné = OK (`pont-vitrine`) ; LATÉRAL = non gardé (cf. [[game-iso-depth-z-secondary]] corrigée).

**Santé/perf** : `roofPans` cc=149, `buildComposition` cc=127, 15+ fonctions cc≥20 toutes couches ; `IsoStage.tsx` churn 210 commits/10 semaines (393 L).

Nouvelle doc **agent-facing** des règles WFRP4 RAW sous `docs/raw/`. But = répondre vite et sûrement à « est-ce que X est RAW, et que dit la source ? » quand la règle est **éclatée sur plusieurs chapitres ET plusieurs livres**. Pas une doc joueur.

Format : 1 fichier par **domaine**, 1 section `##` = 1 **topic** = synthèse fidèle + **Sources RAW** (TOUTES les refs `LIVRE NN l.X-Y` consolidées, tous livres) + citations verbatim + **Voir aussi** (renvois règle→règle) + **Implémente** (module `src/engine/`). Spine : `00-index.md`, `sources.md` (14 livres + convention de réf identique aux commentaires de code), `code-map.md` (inverse module→topics, pour l'audit de fidélité).

**Corpus RAW = 14 livres** (CLAUDE.md § Sources VF corrigé le 2026-06-20) : LDB, ADE I, ADE II, AA, ZI, Middenheim, EDO, EDOC, T2, T2C, T3, Altdorf, Ubersreik, NADAJ. Les tomes/suppléments sont des **sources de règles** (donnée mécanique = RAW, pas la prose). **Boîte d'Initiation EXCLUE** (Starter Set, ruleset simplifié divergent).

Build = **workflow multi-modèles par domaine** : survey (Haiku livres pauvres / Sonnet denses, 1 agent/livre) → synthèse (Opus) → vérif fidélité adversariale (Sonnet) → code-map. Assemblage déterministe : `node scripts/raw/assemble-domain.mjs <output.json> <Titre>` (lit le JSON renvoyé par le workflow → écrit `docs/raw/<domaine>.md` + `code-map.md`). **Pilote Combat livré** (14 topics, 377 passages, 14 livres).

**Fan-out = AUTONOME (exigence user)** : à ~20 domaines, pas de config par domaine à la main ni de babysitting, sinon « on ne s'en sort pas ». Le workflow doit (a) **s'auto-cadrer** : découvrir ses chapitres/livres depuis les `00 - Index.md` + grep des termes du domaine — on ne lui passe que le NOM du domaine (plus de `coverageRefs` manuels ; bonus : `args` ne s'injecte pas avec `scriptPath`, donc auto-cadrage = obligatoire) ; (b) **s'auto-valider** : la boucle d'audit de complétude + la vérif de fidélité SONT les garde-fous qui remplacent ma surveillance (jusqu'à « sec »). Je ne revois que l'**agrégat final** (1 agent frais juge l'ensemble), lancé en quelques LOTS de noms.

**Structure workflow COMPLÈTE** (`scripts/raw/atlas-domain.workflow.js`) : Cartographie de surface (tous chapitres → inventaire « à couvrir ») → Taxonomie sur l'inventaire → Survey 14 livres → Synthèse (tables VERBATIM) → **Audit de complétude EN BOUCLE** (gap-finder survolé/raté → augmente/ajoute topics → ré-audite, loop-until-dry) → Vérif fidélité → Code-map. Manquaient au 1er jet : cartographie, audit-complétude, boucle. Bar = AUTOSUFFISANT (reproduire tables/valeurs verbatim, INDÉPENDANT de notre code car il sert à l'auditer — jamais renvoyer à `src/data`).

**Réalisateur = couche de cadence PURE, pas d'état dérivé synchronisé** (évite le smell garde-de-synchro [[credo-exemples-calibrants]]) :
- `src/state/combatDirector.ts` (feuille, baril) : `beatHold(get, base)` = `TEMPO[base] × ton` (crit/mort→grave ×1.5, Peur→strong ×1.25) ; SEUL endroit cadence×importance. `TEMPO` recentré (postAttack 700, turnHandoff/enemyAdvance 650, aimTelegraph 850, moveTelegraph 400). Tous les timers d'après-action IA (`combatFlow`) + auto-cadence (`combatAuto`) y passent.
- Bannière (`CombatBanner`) = **projection** de 2 sources existantes, AUCUN champ `combatHeadline` : `narrateIntent(actorAim)` pendant le télégraphe, sinon `combatFeed(battle.log,1)`. Ton dérivé du kind (`toneOf` dans `combatNarration.ts`, `NarratedLine.tone`) → CSS `.cb-tone-strong/grave`.
- **Télégraphe attaque** : `actorAim.melee?:boolean` consolidé en `actorAim.kind:'melee'|'charge'|'ranged'|'cast'` (type `ActorAim` dans `combatLog.ts`). Mêlée/charge/sort télégraphient comme le tir (~0.85 s) ; `attackThenAdvance` défaut delay = aimTelegraph ; case 'shoot' ne double-télégraphie plus.
- **Télégraphe déplacement ennemi** (parité héros) : nouveau `actorMove:{id,path}` (manifest `stateFields`, resetOn combatStart) ; le move case pose `actorMove`, tient `beatHold('moveTelegraph')`, PUIS glisse (move différé dans setTimeout). Rendu via `movePreviewEls` (paramétré `color`, rouge `#e0533a`).
- Callbacks différés (déplacement + attaque) **relaunch-safe** : `if (!b||b.over||!b.combatants.includes(enemy)) return;` — sinon un callback en vol réécrit l'ancien combat → soft-lock.

**Soft-lock Auto-combat « héros crité en défense » (bug PRÉ-EXISTANT trouvé pendant la session, PAS causé par la readability) :** en cadence `auto`, un héros qui prend un Coup Critique en se défendant → `defenseConfirm`/`defenseCancel` (combatSlice ~1431/1470) nullifie `pendingDefense`, `applyAttackResult` empile l'étape `cons-deviation` et renvoie `suspended`, MAIS le `if (suspended) return` ne faisait PAS avancer le curseur hors de l'étape `defense` orpheline — alors que le cas `fumble` 12 lignes plus bas le fait (`cascadeNext()`). Le pilote auto boucle alors sur une étape défense qu'il ne peut résoudre (`pendingDefense` null → `defenseConfirm` no-op). Fix : dans les DEUX (`defenseConfirm`+`defenseCancel`), sur `suspended`, `if (casc?.participants[casc.cursor]?.jet==='defense') get().cascadeNext()` (garde idempotente, manuel inchangé). Régression : store.test.ts « Déviation Critique — défenseur héros crité ». **Méthode de diag (utile) :** soft-lock = `pendingCascade` figé (échantillonner 2× → `changed:false`), lire l'étape courante (`participants[cursor].jet/kind`) ; ici `defense` + `pendingDefense:null` + 0 modale DOM (auto cache via willAutoResolve). Débloquer live sans reload : `store.cascadeNext()`.
